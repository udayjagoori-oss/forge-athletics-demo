# FORGE ATHLETICS — Gym Website Concept

A responsive, multi-section single-page website built as a fictional portfolio demo. It uses plain HTML, CSS and JavaScript, so it requires no build step or paid dependencies.

## Preview locally

1. Extract the ZIP folder.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for Google Fonts and the remote Unsplash photography. The layout and text still load without them.

## Before using for a real client

- Replace the fictional brand name, copy, names, images and demo address/hours with approved business details.
- Replace illustrative membership prices and all fictional trainer content.
- Replace the testimonial placeholder only with genuine, approved feedback.
- In `script.js`, set `WHATSAPP_NUMBER` to a real WhatsApp number in international format using digits only, such as `919876543210` (example format only).
- Connect the contact form to a trusted form endpoint or backend. At present it only validates fields in the browser. It does not transmit or store submissions.
- Configure the real client's domain, hosting, privacy notice and any applicable consent requirements.
- Update the footer credit `[YOUR NAME / STUDIO]`.

## Project files

- `index.html` — all page sections and accessible semantic structure
- `styles.css` — responsive layout, visual styles and motion preferences
- `script.js` — mobile navigation, pricing CTA prefill, WhatsApp placeholder, client-side form validation and reveal effects

## Photography and fonts

Images are loaded from Unsplash image URLs; Google Fonts supplies Barlow Condensed and DM Sans. Confirm image licensing and client suitability when launching a commercial site, and self-host assets if desired.
